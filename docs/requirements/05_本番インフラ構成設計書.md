## 1. 推奨構成

### 1.1 構成比較

| 構成 | 初期コスト | 月額目安 | スケーラビリティ | 運用負荷 | 推奨度 |
|------|----------|---------|----------------|---------|--------|
| **AWS (ECS Fargate)** | 中 | 5,000〜30,000円 | 高 | 低 | ★★★★★ |
| **AWS (EC2 単体)** | 低 | 3,000〜10,000円 | 中 | 中 | ★★★★☆ |
| **さくらVPS + Docker** | 低 | 1,000〜5,000円 | 低 | 高 | ★★★☆☆ |
| **Fly.io** | 低 | 2,000〜8,000円 | 高 | 低 | ★★★★☆ |

### 1.2 推奨: AWS 構成（初期〜中規模）

```
[CloudFront (CDN)]
    │
[ALB (HTTPS終端・SSL証明書)]
    │
[ECS Fargate / EC2]
    ├── app (PHP-FPM)
    ├── web (Nginx)
    └── worker (Queue Worker)
    │
[RDS MySQL]
    │
[S3 (画像ストレージ)]
    │
[SES (メール送信)]
    │
[ElastiCache Redis (将来)]
```

## 2. サービス別設計

### 2.1 コンピューティング

**初期: EC2 単体 → 成長後: ECS Fargate**

| 項目 | 初期 (EC2) | 成長期 (ECS) |
|------|-----------|-------------|
| インスタンス | t3.small (2vCPU/2GB) | Fargate 0.5vCPU/1GB |
| 台数 | 1台 | 2台〜 (Auto Scaling) |
| デプロイ | SSH + Git Pull | ECR + ECS デプロイ |
| 月額目安 | ~3,000円 | ~5,000円〜 |

### 2.2 データベース

**RDS MySQL 8.0**

| 項目 | 設定 |
|------|------|
| インスタンス | db.t3.micro (初期) → db.t3.small (成長期) |
| ストレージ | 20GB gp3 (Auto Scaling 有効) |
| Multi-AZ | 初期は無効、本番安定後に有効化 |
| バックアップ | 自動バックアップ 7日間保持 |
| 暗号化 | 有効 |
| 月額目安 | ~2,000円 |

### 2.3 ストレージ

**S3 (プロフィール画像・本人確認書類)**

| バケット | 用途 | アクセス |
|---------|------|---------|
| `palette-public-assets` | プロフィール画像・ポートフォリオ | CloudFront 経由で公開 |
| `palette-private-assets` | 本人確認書類 | 署名付きURL のみ |

```env
# .env.production に追加
FILESYSTEM_DISK=s3
AWS_BUCKET=palette-public-assets
```

### 2.4 メール

**Amazon SES**

| 項目 | 設定 |
|------|------|
| リージョン | ap-northeast-1 (東京) |
| 送信元ドメイン | palette.example.com (DKIM + SPF 設定) |
| バウンス処理 | SNS → Lambda で自動処理 |
| 月額目安 | ~100円 (月1,000通以下) |

### 2.5 CDN

**CloudFront**

| 項目 | 設定 |
|------|------|
| オリジン | ALB + S3 |
| SSL証明書 | ACM (無料) |
| キャッシュ | 静的アセット 30日 / 画像 7日 |
| 圧縮 | Gzip + Brotli 自動 |

## 3. デプロイフロー

### 3.1 初期 (EC2 直接デプロイ)

```bash
#!/bin/bash
# deploy.sh

set -e

cd /var/www/palette

# メンテナンスモード
php artisan down

# コード取得
git pull origin main

# 依存関係
composer install --no-dev --optimize-autoloader

# マイグレーション
php artisan migrate --force

# キャッシュ
php artisan config:cache
php artisan route:cache
php artisan view:cache

# アセットビルド
npm ci && npm run build

# キューワーカー再起動
php artisan queue:restart

# メンテナンスモード解除
php artisan up

echo "Deploy completed at $(date)"
```

### 3.2 成長期 (GitHub Actions + ECS)

```yaml
# .github/workflows/deploy.yml
name: Deploy to Production
on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Build Docker image
        run: docker build -t palette-app .
      - name: Push to ECR
        run: |
          aws ecr get-login-password | docker login --username AWS --password-stdin $ECR_REGISTRY
          docker tag palette-app:latest $ECR_REGISTRY/palette-app:latest
          docker push $ECR_REGISTRY/palette-app:latest
      - name: Deploy to ECS
        run: aws ecs update-service --cluster palette --service palette-app --force-new-deployment
```

## 4. 監視・アラート

### 4.1 必須監視項目

| 項目 | ツール | 閾値 |
|------|--------|------|
| サーバー死活 | CloudWatch / UptimeRobot | 1分間隔 |
| CPU使用率 | CloudWatch | >80% で警告 |
| メモリ使用率 | CloudWatch | >85% で警告 |
| ディスク使用率 | CloudWatch | >80% で警告 |
| 5xx エラー率 | CloudWatch + ALB | >1% で警告 |
| レスポンスタイム | CloudWatch + ALB | p95 > 3秒で警告 |
| DB接続数 | RDS メトリクス | >80% で警告 |

### 4.2 エラー監視

## 5. セキュリティ

| 項目 | 対策 |
|------|------|
| SSH | 鍵認証のみ、ポート変更、IP制限 |
| セキュリティグループ | 80/443 のみ公開、DB は VPC 内のみ |
| WAF | AWS WAF (OWASP Top 10 ルールセット) |
| シークレット管理 | AWS Secrets Manager or SSM Parameter Store |
| ログ | CloudWatch Logs に集約、90日保持 |
