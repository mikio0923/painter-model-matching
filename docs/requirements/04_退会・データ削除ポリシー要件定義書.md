# 退会・データ削除ポリシー 要件定義書

> 作成日: 2026-04-16
> ステータス: ドラフト（レビュー待ち）

---

## 1. 概要

ユーザーのアカウント退会機能およびデータ削除ポリシーを定義する。
個人情報保護法に準拠し、ユーザーの権利を保護しつつサービスの健全性を維持する。

---

## 2. ビジネス要件

### 2.1 退会の原則

1. ユーザーはいつでも自由に退会できる
2. 退会手続きは簡潔で、不当に引き留めない
3. 退会後のデータ処理は透明性を持って説明する
4. 法的義務のあるデータは適切な期間保持する

### 2.2 退会できない条件（ブロッカー）

| 条件 | 理由 |
|------|------|
| 進行中の依頼がある（画家の場合） | モデルへの責任が残っている |
| 承認済みの応募が完了していない（モデルの場合） | 画家への責任が残っている |
| 未精算の報酬がある（決済実装後） | 金銭的義務が残っている |
| 未解決のトラブル報告がある | 調査完了まで保留 |

上記に該当する場合は、退会画面で理由を表示し、先に解決するよう案内する。

## 3. 退会フロー

### 3.1 フロー図

```
1. ユーザーがアカウント設定 → 「退会する」をクリック
2. 退会理由の選択（任意・アンケート形式）
3. 退会の注意事項を表示（データ削除範囲の説明）
4. パスワード再入力で本人確認
5. 「退会する」ボタンで確定
6. 確認メール送信（「退会処理が完了しました」）
7. 即時ログアウト
8. 猶予期間開始（30日間）
9. 猶予期間中にログイン → 復帰可能
10. 猶予期間終了 → データ削除バッチ実行
```

### 3.2 退会理由（アンケート選択肢）

| # | 選択肢 |
|---|--------|
| 1 | マッチングできなかった |
| 2 | サービスの使い方がわかりにくかった |
| 3 | 他のサービスを利用することにした |
| 4 | トラブルがあった |
| 5 | 一時的に利用を中止したい |
| 6 | その他（自由記述） |

## 4. データ処理ポリシー

### 4.1 データ分類と処理方法

| データ種別 | 退会時の処理 | 猶予期間後の処理 | 保持期間 |
|-----------|-------------|----------------|---------|
| **ユーザーアカウント** | SoftDelete（論理削除） | 匿名化 | 匿名化後は無期限 |
| **プロフィール情報** | 非公開化 | 物理削除 | 猶予期間終了後に削除 |
| **プロフィール画像** | 非公開化 | ストレージから物理削除 | 猶予期間終了後に削除 |
| **本人確認書類** | 即時削除 | — | 退会時に即時削除 |
| **メッセージ** | 匿名化（送信者名を「退会済みユーザー」に） | 本文は保持 | 相手方の利便性のため保持 |
| **レビュー** | 匿名化（投稿者名を「退会済みユーザー」に） | 本文は保持 | サービスの信頼性維持のため保持 |
| **依頼（画家の場合）** | 公開中の依頼をクローズ | 依頼データは保持 | 応募者の利便性のため保持 |
| **応募履歴** | 非公開化 | 匿名化 | 猶予期間終了後に匿名化 |
| **お気に入り** | 物理削除 | — | 退会時に即時削除 |
| **通知** | 物理削除 | — | 退会時に即時削除 |
| **決済情報（将来）** | Stripe Connected Account 削除 | 取引履歴は匿名化して保持 | 法的義務：7年間保持 |
| **メールアドレス** | ハッシュ化して保持 | — | 再登録防止のため保持 |

### 4.2 匿名化の定義

```php
// 匿名化処理の例
$user->update([
    'name' => '退会済みユーザー',
    'email' => hash('sha256', $user->email) . '@deleted.palette.local',
    'password' => Hash::make(Str::random(64)),
    'phone_number_part1' => null,
    'phone_number_part2' => null,
    'phone_number_part3' => null,
    'postal_code_part1' => null,
    'postal_code_part2' => null,
    'prefecture' => null,
    'city' => null,
    'street_number' => null,
    'building_name' => null,
    'deleted_at' => now(),
    'anonymized_at' => now(),
]);
```

## 5. 技術設計

### 5.1 DB変更

#### `users` テーブルへのカラム追加

| カラム | 型 | 説明 |
|--------|-----|------|
| deleted_at | timestamp(nullable) | SoftDeletes 用 |
| deletion_requested_at | timestamp(nullable) | 退会申請日時 |
| anonymized_at | timestamp(nullable) | 匿名化完了日時 |
| deletion_reason | string(nullable) | 退会理由 |
| deletion_feedback | text(nullable) | 退会時の自由記述フィードバック |

#### User モデルに SoftDeletes 追加

```php
use Illuminate\Database\Eloquent\SoftDeletes;

class User extends Authenticatable
{
    use HasFactory, Notifiable, SoftDeletes;
}
```

### 5.2 実装コンポーネント

| コンポーネント | 説明 |
|---------------|------|
| `AccountDeletionController` | 退会フォーム表示・退会処理実行 |
| `AccountDeletionService` | 退会ロジック（SoftDelete + 関連データ処理） |
| `AnonymizeDeletedUsersCommand` | 猶予期間終了後のデータ匿名化バッチ（Artisan） |
| `AccountDeletionMail` | 退会完了メール |
| `AccountRestoredMail` | アカウント復帰メール |

### 5.3 退会処理の実装

```php
class AccountDeletionService
{
    public function requestDeletion(User $user, ?string $reason, ?string $feedback): void
    {
        // 退会ブロッカーチェック
        $this->validateCanDelete($user);

        // 進行中の依頼をクローズ
        $user->jobs()->where('status', 'open')->update(['status' => 'closed']);

        // プロフィールを非公開に
        $user->modelProfile?->update(['is_public' => false]);

        // お気に入り・通知を削除
        $user->favorites()->delete();
        $user->notifications()->delete();

        // 本人確認書類を即時削除
        $this->deleteIdentityDocuments($user);

        // 退会情報を記録
        $user->update([
            'deletion_requested_at' => now(),
            'deletion_reason' => $reason,
            'deletion_feedback' => $feedback,
        ]);

        // SoftDelete
        $user->delete();

        // 退会完了メール送信
        Mail::to($user->email)->send(new AccountDeletionMail($user));
    }
}
```

### 5.4 匿名化バッチ（猶予期間終了後）

```php
// app/Console/Commands/AnonymizeDeletedUsersCommand.php
// 毎日深夜に実行

class AnonymizeDeletedUsersCommand extends Command
{
    protected $signature = 'users:anonymize-deleted';

    public function handle(): void
    {
        $gracePeriodDays = 30;

        $users = User::onlyTrashed()
            ->where('deleted_at', '<', now()->subDays($gracePeriodDays))
            ->whereNull('anonymized_at')
            ->get();

        foreach ($users as $user) {
            // プロフィール画像をストレージから削除
            $this->deleteProfileImages($user);

            // ユーザーデータを匿名化
            $this->anonymizeUser($user);

            // メッセージ・レビューの送信者名を匿名化
            $this->anonymizeRelatedData($user);
        }
    }
}
```

### 5.5 アカウント復帰

```php
// 猶予期間中にログイン試行した場合
class LoginController
{
    public function authenticate(Request $request)
    {
        $user = User::withTrashed()
            ->where('email', $request->email)
            ->first();

        if ($user && $user->trashed() && $user->anonymized_at === null) {
            // 猶予期間内 → 復帰確認画面を表示
            return redirect()->route('account.restore.confirm', [
                'token' => encrypt($user->id),
            ]);
        }

        // 通常のログイン処理...
    }
}
```

## 7. 法的要件

| 項目 | 対応 |
|------|------|
| 個人情報保護法 第28条 | ユーザーからの削除請求に対応（退会機能で充足） |
| 個人情報保護法 第30条 | 利用停止請求に対応（退会 = 利用停止） |
| 利用規約 | 退会条件・データ処理方針を明記 |
| 電子帳簿保存法 | 決済関連データは退会後も7年間保持が必要 |
| 特定電子メール法 | 退会後のマーケティングメール送信禁止 |
