# Voice & Tone — 文言と表現のガイドライン

ビジュアルだけでなく**文言**も Palette のブランドの一部。UI コピー、エラーメッセージ、メールテキストの全てに適用する。

## ブランドパーソナリティ

Palette を「人」に例えるなら：

> **30代前半・東京在住・アートとファッションに造詣が深い・誠実だが堅苦しくない・少しだけ知的で品がある・押し付けがましくない**

## トーン三原則

### 1. **品がある（Refined）**
- 過剰な感嘆符・絵文字は使わない
- カジュアルすぎる表現を避ける
- でも堅苦しくはしない

```
❌ NG: 「ばっちりOK！🎉 最高のマッチ見つけよう✨」
⭕ OK: 「マッチングが完了しました。プロフィールから連絡を取ってみてください。」
```

### 2. **明瞭（Clear）**
- 専門用語は使わない（やむを得ない時は補足）
- 1文が長すぎない（40字を目安）
- 何をすればよいかが明確

```
❌ NG: 「データの整合性確保のため、システム側で自動的にマージ処理を実行いたしました」
⭕ OK: 「変更内容を保存しました」
```

### 3. **温かい（Warm but professional）**
- 命令口調を避ける（「〜してください」より「〜していただけます」）
- ユーザーを責めない
- でも馴れ馴れしくしない

```
❌ NG: 「入力内容にエラーがあります。もう一度入力し直してください。」
⭕ OK: 「入力内容をご確認ください。"電話番号" の形式が正しくないようです。」
```

## マイクロコピー集

### ボタン文言

| シーン | 推奨 | NG |
|-------|------|-----|
| 保存 | 「保存」「変更を保存」 | 「OK」「決定」 |
| 送信 | 「送信」「申し込む」 | 「Submit」「Go」 |
| キャンセル | 「キャンセル」「やめる」 | 「No」 |
| 削除 | 「削除」「削除する」 | 「消去」「Remove」 |
| 確認 | 「確認」「内容を確認」 | 「Check」 |
| 詳細 | 「詳細を見る」「もっと見る」 | 「Learn More」 |
| 戻る | 「戻る」「← 一覧に戻る」 | 「Back」 |

### 空状態

| 状況 | 推奨文言 |
|-----|---------|
| データなし | 「まだ何もありません」 |
| 検索結果なし | 「該当する結果が見つかりませんでした」 |
| エラー | 「読み込みに失敗しました。少し時間を置いて再度お試しください」 |
| 権限なし | 「このページを表示する権限がありません」 |

### 確認ダイアログ

| 操作 | 推奨文言 |
|-----|---------|
| 削除全般 | 「この◯◯を削除しますか？この操作は取り消せません。」 |
| 退会 | 「本当に退会しますか？{N}日間は復帰可能ですが、それ以降は完全に削除されます。」 |
| 公開停止 | 「プロフィールを非公開にしますか？" |

### 通知メッセージ

| 種類 | 推奨パターン |
|-----|------------|
| 成功 | 「{動詞}しました」(例: 保存しました、登録しました、削除しました) |
| 警告 | 「{条件}のため、{結果}できません」 |
| エラー | 「申し訳ございません。{原因}が発生しました」 |

### 入力プレースホルダ

シンプルかつ具体的に：
- 「東京都」（都道府県）
- 「090-1234-5678」（電話番号）
- 「ポートレート、撮影同行...」（タグ）

## メール文言ガイド

### 件名

```
【{サービス名}】{要件}
```

例：
- 【Palette】依頼に新しい応募がありました
- 【Palette】応募が承認されました
- 【Palette】メールアドレス認証のお願い

### 本文の構成

```
{ユーザー名} さん、こんにちは。

{要件の簡潔な説明（1〜2文）}

{詳細・操作内容}

{CTA ボタン}

{追加情報・注意点}

──────
{サービス名} カスタマーサポート
```

### 避けるべき表現

- ❌ 「！」「!!」 → 「。」
- ❌ 「ご利用ありがとうございます！」（過剰な感謝）
- ❌ 「お得な情報」「キャンペーン」（押し売り感）
- ❌ 顔文字・絵文字

## 画家向け / モデル向けの呼び分け

| 主体 | 呼称 |
|------|------|
| 画家ユーザー | 「画家」「クリエイター」（場面による） |
| モデルユーザー | 「モデル」 |
| 両者総称 | 「利用者」「ユーザー」 |
| 自分のこと | サービス名で呼ぶ「Palette は...」 |

## 専門用語の使い方

サービス内では一般用語を優先：

| 専門用語 | 推奨表現 |
|---------|---------|
| マッチング成立 | 「依頼が承認されました」「応募が通りました」 |
| エンゲージメント | 「やりとり」 |
| ポートフォリオ | 「作品集」「過去の作品」 |
| トランザクション | 「取引」 |

## 日本語特有のルール

- **半角英数前後の半角スペース**: 『「Palette」 のサービス』ではなく『「Palette」のサービス』（不要）
- **数字**: アラビア数字を使う（「3つ」より「3つ」、「5,000円」）
- **記号統一**: 「・」と「、」は混在させない、リスト区切りは「・」

## 最重要：ユーザー視点の言い換え

サービス側の都合を主語にせず、ユーザーの体験を主語に。

```
❌ システム側「このリクエストは処理できませんでした」
⭕ ユーザー側「申し訳ございません、この操作は現在ご利用いただけません」

❌ システム側「ユーザーは入力エラーを起こしました」
⭕ ユーザー側「メールアドレスの形式をご確認ください」
```
